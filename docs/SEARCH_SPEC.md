# HODY GUITAR｜取り扱い商品ページ・検索機能仕様 v1.0

作成日：2026-11-04／対象：`selection.html`（実装済み）

> 更新：検索挙動・予約連携はユーザー承認済みの改訂計画を適用しました。SPパネルは初期展開・検索後収納・リセット後展開です。画像は更新データの全12点を使用し、0件シルエットはFigma正式素材を `assets/images/selection/empty-guitar.png` に保存しました。以下の元資料の提案記述より、この更新と `SELECTION_IMPLEMENTATION.md` を優先します。仮価格・説明・分類の公開承認は別途必要です。

> **重要**：ここでいう「提案」は実装を進めるための仕様案であり、ユーザーが確定した仕様ではありません。PC/SPの添付カンプと実サイトの既存コードを優先してください。商品価格・紹介文・一部のタグは架空店舗用の仮設定です。

## 1. デザインカンプから確認できた画面

| 状態 | PCカンプ | SPカンプ | 表示要素 |
|---|---|---|---|
| 初期一覧 | `references/PC_SELECTION01.jpg` | `references/SP_SELECTION01.jpg` | ページ見出し、検索フォーム、商品カード、検索結果、予約CTA、店舗写真、フッター |
| 絞り込み結果あり | `references/PC_SELECTION02.jpg` | `references/SP_SELECTION02.jpg` | 適用条件、検索結果件数、該当商品のみ |
| 絞り込み結果なし | `references/PC_SELECTION03.jpg` | `references/SP_SELECTION03.jpg` | 適用条件、0件、シルエット画像と案内文 |

PCでは左に絞り込みパネル、右に3列のカード。SPでは検索パネルが展開／収納でき、カードは1列。**カンプの一部の商品カードは同一モデル114ceの繰り返し**ですが、商品マスターは提供された12機種を重複なく登録します。

**カンプの表示商品数（例：4件／6件）と、この12機種マスターで実計算した件数が異なる場合は、件数を固定値にせず実際の検索結果数を表示します。** 数を合わせるために公式のサイズ情報を改変しないこと。

## 2. データの管理

- マスターは `data/products.json`。編集用コピーは `data/products.csv` および `HODY_商品マスター.xlsx`。
- `price_yen` は **税込・架空店舗用の仮価格**であり、メーカー希望小売価格や実店舗価格ではありません。公開前に全12件を承認・修正する必要があります。
- `description` は新規に提案した文章。`tagline` / `site_role` はユーザーの添付表から転記したサイト内の役割。
- `body_size` はUI用に「小さめ／標準／大きめ」へ分類した編集案。客観的な形状は `body_shape_reference` に記録。
- `tone_impressions` と `playing_styles` は、試奏のきっかけになるように付けた**編集上の提案タグ**。音色や演奏可否を断定する仕様表現ではありません。
- `amp_connection` は真偽値で、**`null` は未確認**（`false` とは異なります）。仕様が不明な個体に「接続できない」を自動適用しないこと。
- 画像は `image_src` が設定済みの場合のみ表示。TOPから再利用できるのは最初の3点のみ（J-45／D-28／114ce）。不足の9点を既存画像の複製や別の機種で代替しないこと。

## 3. 検索UIの選択肢【提案・要承認】

| フィールド名 | 選択肢 | マッチ条件 |
|---|---|---|
| 価格帯 | すべて、15万円未満、15〜30万円未満、30〜50万円未満、50万円以上 | 税込 `price_yen` から範囲判定（上限は含まない） |
| ボディサイズ | すべて、小さめ、標準、大きめ | `body_size` 完全一致 |
| 弾き方 | すべて、コード・ストローク、指弾き、どちらも | `playing_styles` に該当値を含む。「どちらも」は2値とも含む場合 |
| 音の印象 | すべて、明るい、力強い、バランスのよい | `tone_impressions` に該当値を含む |
| アンプ接続 | すべて、アンプ接続できる、アンプ接続しない | `true`／`false` 完全一致。`null` は「すべて」でのみ表示 |

**診断の3問はこのページでは実装しません。** 将来的には「音の印象」「サイズ」「弾き方」の共通タグを利用できます。TOPの診断実装は別タスクです。

## 4. 絞り込みの操作仕様【提案】

1. 初期画面では12機種すべてを `sort_order` 昇順で表示。別途ページネーションを勝手に作らない。
2. 各プルダウンの「すべて」は、そのフィールドの条件を適用しない。
3. 選択変更だけでは一覧は変化させず、**「検索」押下時**に条件を適用する。
4. フィールド間は **AND条件**、`playing_styles` や `tone_impressions` の配列内は前項の判定を使用する。
5. 「検索結果 X件」の件数は `filteredProducts.length` から都度計算する。**カンプにある例示件数のハードコード禁止**。
6. 適用条件の表示は**最後に検索を押した条件**を元に生成。編集中のプルダウン値とは区別する。
7. 「条件をリセット」を押すとすべてのプルダウンを「すべて」に戻し、適用条件と結果を初期状態に戻す。
8. SPの絞り込みパネルは開閉可能。閉じても選択値・適用条件・検索結果を保持する。初期状態は閉じる想定だが、Figmaのプロトタイプで指定があればそちらを優先。
9. キーボードでもプルダウン選択・検索・リセット・パネル開閉が行えるようにする。
10. `price_yen` は仮価格のため、公開前に値を再確認する。価格未設定の商品を追加する際は「すべて」では表示し、価格条件を指定した場合は価格未設定商品を除外する。

## 5. 画面状態

### 5.1 検索結果あり

表示するカード情報：
- 商品画像（正しい機種のものだけ）
- 「サイト内での役割」／キャッチコピー
- ブランド
- モデル名
- 説明文
- `価格：xxx,xxx円(税込)`
- **「このギターを試奏する」** CTA

PCは3列、SPは1列。商品画像の枠とトリミング・カード幅・行高はFigmaに準拠。

### 5.2 検索結果なし

- 件数は `0件`。
- `assets/images/guitar-outline.png`（既存のシルエット）を使用。
- 文言：「条件に合うギターが見つかりませんでした」
- 文言：「少し条件を変えて、もう一度検索してみてください。」
- 他セクション（下部青いCTA、店舗写真、フッター）は消さない。

### 5.3 条件表示

カンプにある「絞り込み条件」「ボディサイズ：小さめ」「音の印象：力強い」等は、**適用済み条件**から動的に生成する。同じ結果でPC・SPの表記は揃える。選択条件がゼロのときは適用条件ラベルの表示位置をカンプで確認。

## 6. 試奏予約との連携【重要】

TOPの `js/reservation.js` は現在、初期表示時に存在する `.js-open-reservation` にイベントリスナーを登録し、`button.dataset.product` をダイアログの `#reserve-product` の `value` と照合します。また `#reserve-product` の `<option>` は、TOPでは「未定・相談して決めたい」「Gibson J-45」「Martin D-28」「Taylor 114ce」のみです。

そのため、商品カードをJSONから**後で描画するだけでは予約ボタンが動かない**可能性があります。以下を両方行ってください。

- 新規作成される商品カードも開けるよう、予約ボタンはイベント委譲で拾うか、カード描画後に正しくリスナーを追加する。
- 商品マスター12件の `display_name` を予約セレクトに追加する。選択したカードの `display_name` を `data-product` などで渡す。既存モーダルのPC中央表示・SP右スライド・Esc・フォーカス復帰を壊さない。

本番予約の送信処理・確認画面はカンプ未提示のため**今回実装しない**。
